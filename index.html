MeetingMind

Meeting assistant that automatically captures every meeting and turns it into searchable, interactive notes the moment the call starts. One click—or none with auto-record—and your mic plus system audio are saved as a compact M4A file, transcribed in real time, and organized into clean markdown summaries. No virtual audio drivers. No cloud uploads.

Live Transcription

WhisperKit-powered transcription delivers instant, speaker-attributed notes in markdown. Dual-source capture mixes mic and system audio with adaptive gain to prevent echo and clipping. Automatic Zoom detection aligns recordings precisely with meeting start and end times.

Embedded AI Assistant

Stay present with an on-device AI that highlights takeaways, tracks action items by speaker, and answers queries during the call. Supports chat prompts, document uploads, screenshots, and smart templates. Mark details with ^important^ in the AI chat window.

Private, Flexible Processing

Privacy-first architecture keeps everything on-device. Connect local Ollama, LM Studio, LocalAI, Jan, or OpenRouter keys for deeper analysis with dynamic model discovery. Three recording modes handle any setup without missing a beat.

Built for macOS

Optimized for Apple Silicon on macOS 13 Ventura or later. Local caching, conflict-free naming, and automatic cleanup maintain a tidy library. Advanced detection survives window transitions and screen sharing.

How It Works

1. Start Recording

One-click or auto-detects meetings. Captures mic and system audio as compact M4A—no drivers needed.

2. Real-Time Transcription

WhisperKit transcribes on-device, attributing speakers and generating markdown summaries instantly.

3. AI Analysis

Embedded assistant tracks action items, highlights key points. Query live or connect local models for more.

4. Search and Share

Build a searchable archive. Export clean notes, recaps, or full transcripts effortlessly.
